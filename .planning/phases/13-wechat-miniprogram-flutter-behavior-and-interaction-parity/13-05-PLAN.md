<task id="13-05-02">
<title>Create study feed item helper</title>
<action>
Create a pure TS helper that mirrors Flutter `_feedItems`:
- input: `session`, `lastSubmittedQuestion`, `lastSubmittedResult`, `lastSubmittedResponse`, and `completion`
- output item kinds: `answered`, `unanswered`, `completion`
- answered items include response override when question ids match
- current unanswered question is appended only when not already answered and no completion exists
- completion item is appended when completion exists
</action>
<acceptance_criteria>
- A file under `apps/wechat_miniprogram/src` contains `type StudyFeedItem`.
- The helper contains `answered`.
- The helper contains `unanswered`.
- The helper contains `completion`.
- The helper contains `lastSubmittedResponse`.
</acceptance_criteria>
</task>

<task id="13-05-03">
<title>Implement vertical feed rendering</title>
<action>
Update `pages/study/index.tsx` to render the feed with WeChat-compatible vertical paging. Prefer `Swiper` with `vertical` and `current` state if it preserves inputs; otherwise use a page-snapping scroll implementation. The feed must:
- show answered question pages
- show the current unanswered question page
- append a completion page after completion
- jump to the latest page after submit
- update visible page index on page change
- settle or clear stale input when leaving the current unanswered page
</action>
<acceptance_criteria>
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `Swiper` or `scroll-y`.
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `vertical`.
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `visiblePageIndex` or `currentPage`.
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `feedItems`.
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `completion`.
</acceptance_criteria>
</task>

<task id="13-05-04">
<title>Wire answer actions and result pages</title>
<action>
Update Study flow to:
- choose response from explicit choice, selected choice, or text input
- reject empty response unless revealing answer
- call `sdk.study.submitAnswer(questionId, response, responseTimeMs)`
- merge latest answer into feed state
- show correct/wrong result on answered pages
- support reveal answer with an empty allowed submit if backend supports it
- support mark mastered if `sdk.study.markEntryMastered` exists
- expose hint/comments/dispute buttons as disabled or navigable states if backend endpoints are not available
</action>
<acceptance_criteria>
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `submitAnswer`.
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `responseTimeMs`.
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `markEntryMastered` or a disabled mastered action.
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `reveal`.
- `apps/wechat_miniprogram/src/pages/study/index.tsx` contains `isCorrect`.
</acceptance_criteria>
</task>
