<task id="13-01-02">
<title>Lock drawer-only and tab navigation behavior</title>
<action>
Keep only Today, Plan, Wrong, and Reports in the bottom navigation. Ensure Croc BTI, leaderboard, account/profile/settings, and other secondary surfaces are opened from the drawer or page buttons with `Taro.navigateTo`, not bottom tabs. Keep native WeChat `tabBar` absent from `app.config.ts`.
</action>
<acceptance_criteria>
- `apps/wechat_miniprogram/src/app.config.ts` does not contain `tabBar`.
- `apps/wechat_miniprogram/src/components/Screen.tsx` contains exactly four bottom navigation labels for Today, Plan, Wrong, Reports or their Chinese equivalents.
- `apps/wechat_miniprogram/src/components/Screen.tsx` contains a navigation target for `/pages/croc-bti/index`.
- `apps/wechat_miniprogram/src/components/Screen.tsx` contains a navigation target for `/pages/leaderboard/index`.
</acceptance_criteria>
</task>

<task id="13-01-03">
<title>Wire visible buttons to real page actions</title>
<action>
Audit Today, Plan, Wrong, Reports, Croc BTI, and Study page buttons. Every visible button must either call an SDK method, navigate to a page, toggle an explicit local state, or be disabled with a visible disabled state. Remove decorative no-op buttons. At minimum:
- Today task buttons navigate to `/pages/study/index` with the correct `mode`.
- Today avatar opens the drawer.
- Plan save button calls the plan save handler.
- Plan apply button calls the apply-today handler.
- Wrong-word filter chips update the active filter.
- Reports mode cards toggle selected mode.
- Croc BTI answer chips update answer state.
- Study answer buttons submit or select a response.
</action>
<acceptance_criteria>
- No page file under `apps/wechat_miniprogram/src/pages` contains `onClick={() => {}}`.
- No page file under `apps/wechat_miniprogram/src/pages` contains `onTap={() => {}}`.
- `apps/wechat_miniprogram/src/pages/today/index.tsx` contains `/pages/study/index`.
- `apps/wechat_miniprogram/src/pages/plan/index.tsx` contains `savePlan`.
- `apps/wechat_miniprogram/src/pages/plan/index.tsx` contains `applySavedPlanToToday`.
</acceptance_criteria>
</task>
