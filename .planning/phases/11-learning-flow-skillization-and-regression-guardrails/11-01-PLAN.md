# 11-01 - Create learning-flow skill-standard docs

## Objective

Create project-local skill-standard documentation for the cleaned Flutter learning flow so future work starts from the canonical Phase 10 structure.

## Tasks

1. Create `.planning/skills/learning-flow/INDEX.md` as the entry point for future agents.
2. Create capability guides for:
   - Today / Plan / Study handoff.
   - Study answering and feedback.
   - AI passage/history/import, Wrong Words, and Reports.
   - Bridge/data persistence, leaderboard, image vote/upload, and sidebar entries.
   - Release validation and human UAT.
3. Each guide must include purpose, trigger conditions, canonical files, workflow, verification, known pitfalls, and stale paths to avoid.

## Success Criteria

- A future agent can locate the right guide from `INDEX.md`.
- Every guide points to Flutter/Rust/SQLite canonical files, not React Native active paths.
- Phase 10 human/device verification is carried forward as explicit release validation work.
