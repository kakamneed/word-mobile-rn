# 12-01 - Build Flutter-like mini program shell, custom navigation, tabs, and account drawer

## Objective

Replace the current WeChat-native page chrome and text-only bottom tabs with a reusable Flutter-like shell that all Phase 12 pages can share.

## Read First

- `.planning/phases/12-wechat-miniprogram-flutter-ui-pixel-parity/12-CONTEXT.md`
- `.planning/phases/12-wechat-miniprogram-flutter-ui-pixel-parity/12-UI-SPEC.md`
- `apps/wechat_miniprogram/src/app.config.ts`
- `apps/wechat_miniprogram/src/app.scss`
- Existing page files under `apps/wechat_miniprogram/src/pages/`

## Tasks

1. Change the mini program window/navigation setup so the app shell owns page title and avatar layout instead of the native WeChat title bar.
2. Add shared visual tokens for Flutter parity: background, purple, lavender, text, card, border, radius, shadows, safe-area spacing, and tab-bar dimensions.
3. Create a reusable page shell component for:
   - custom top status spacing,
   - Chinese page title,
   - circular avatar/account button,
   - scrollable content body,
   - custom bottom padding.
4. Replace native four-tab Account navigation with four learning tabs: 今日, 计划, 错词, 报告. Do not add the Flutter AI tab in mini program v1.
5. Implement the selected-tab lavender pill and icon+label rhythm shown in the Flutter bottom bar.
6. Create an account drawer component opened from the avatar button. It must slide over the current page and dim the background.
7. Move account actions into the drawer:
   - 新手引导
   - 鳄bti 学习人格
   - 个人信息
   - 排行榜
   - 设置
   - Check for updates
   - 退出登录
8. Keep deep links to Croc BTI, leaderboard, plan, and account/profile pages working, but do not expose Account as a bottom tab.

## Success Criteria

- `dist/app.json` no longer exposes Account as a bottom tab after build.
- The visible app shell has Chinese titles and avatar buttons on Today, Plan, Wrong Words, and Reports.
- The bottom navigation has four icon tabs and a selected lavender pill.
- No AI tab or Account tab appears in the bottom navigation.
- The drawer visual hierarchy matches Flutter screenshot #12: avatar, username/status, icon rows, dividers, and right-side panel behavior.
- No page depends on the default WeChat navigation title for its visible heading.
