## Tasks

1. Replace the current English `Balanced Study` layout with the Flutter Chinese page:

   - avatar account button
   - purple hero `鳄甲卫`

   - 错词强化

4. Use minus/plus icon buttons and stable numeric boxes so changing values cannot resize rows.

8. Wire all edits through the current plan state/API boundary; do not create a second plan truth source in the UI.

- Plan screenshot matches Flutter #6 in section order, card spacing, controls, and Chinese copy.
