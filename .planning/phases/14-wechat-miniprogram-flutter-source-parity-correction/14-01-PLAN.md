Update `apps/wechat_miniprogram/src/pages/study/index.tsx` session start so it reads `sdk.plan.getActivePlan()` first and passes active-mode `questionTypeWeightsByMode[mode]` unless `resume=1`.

<task id="14-01-02">
<title>Replace repeated one-question mock generation</title>
<action>
Replace `buildQuestionsForSession(mode,total)` so it never produces repeated copies of a single base question for all requested plan slots. Implement this priority:
1. If real HTTP/backend session data is available through `httpClient.startStudySession`, use it unchanged.
2. Otherwise build a deterministic local fixture with at least 20 varied `newWord` questions, 28 varied `review` questions, 34 varied `mixedTest` questions, 26 varied `wrongWordReinforcement` questions, and 4 `rootAffix` questions.
3. For every choice question, produce exactly four cleaned choices when four valid source choices exist.
4. Generate stable `questionId`, `questionIndex` using zero-based source index plus one-based display index, and `totalQuestions`.
Do not cycle `bank[index % bank.length]` when `bank.length < total`.
</action>
<acceptance_criteria>
- `apps/wechat_miniprogram/src/sdk/client.ts` no longer contains `bank[index % bank.length]`.
- `apps/wechat_miniprogram/src/sdk/mockData.ts` contains at least 20 occurrences of `questionId: 'new-`.
- `apps/wechat_miniprogram/src/sdk/mockData.ts` contains at least 4 occurrences of `label: 'D'` inside `questionBank`.
- `npm.cmd run test:study-flow` includes or is updated to include an assertion that a `newWord` session with total 20 has more than one distinct `word`.
</acceptance_criteria>
</task>

<task id="14-01-03">
<title>Port Flutter choice normalization and state helpers</title>
<action>
Add a tested helper module, for example `apps/wechat_miniprogram/src/sdk/studyChoice.ts`, that ports Flutter's choice logic with these exported functions:
- `choiceDisplay(choice,index)` using keys `label`, `Label`, `value`, `Value`, `text`, `Text`, `meaning`, `Meaning`, `word`, `Word`, and fallback labels `A`, `B`, `C`, `D`.
- `normalizeChoiceToken(value)` that trims, lowercases, and collapses whitespace.
- `choiceUserAnswerTokens(result,responseOverride)` splitting on comma, semicolon, slash, Chinese comma, Chinese semicolon, and enumeration comma.
- `resolvedCorrectChoiceTextToken(question,result)`.
- `choiceState(question,result,display,correctTextToken,responseOverride)`.
- `sanitizeChoices(choices)` that removes empty display rows and de-duplicates by normalized display text while preserving original order.
Use returned `StudyResult` for correctness. Do not locally infer correct outcome before SDK submission.
</action>
