# 14-06 - Patch Post-14-05 Parity Regressions From Flutter Source

## Objective

Fix the concrete regressions visible after the first mini-program source-parity rewrite:

1. Study and bottom-nav icons render as literal words (`home`, `close`, `today`, `tune`) or malformed pseudo icons.
2. Multiple mini-program source files still contain mojibake and broken JSX.
3. Study answer feedback no longer shows clear correct/wrong markers, and the page auto-jumps to the next question after submit.
4. Returning to Today mid-session does not surface resume/progress state, and there is no explicit refresh/restart route.
5. `rootAffix` exists in plan data but is not available as a Today task or complete Study flow.
6. Report chart dots/segments are not aligned with the visual chart guides.

## Source Findings

### Flutter Source Anchors

- `apps/flutter_mobile/lib/features/study_screen.dart`
  - `_submit` lines around 154-194: after submit, Flutter sets latest response/current session, then calls `_jumpToCurrentFeedPage()` so the answered card remains visible as part of the feed rather than silently replacing the current question.
  - `_jumpToCurrentFeedPage` lines around 720-731: jumps to the last feed item only after the feed model has the answered item; this is the behavior the mini-program must emulate without skipping the feedback page.
  - `_returnToTodayKeepingProgress` lines around 593-594: closes to Today while preserving progress rather than canceling.
  - `_showExitOptions` lines around 597-630 and `_cancelSession` lines around 575-584: exit must distinguish keep-progress vs cancel.
  - Round action icons around lines 874-893 use `Icons.home_outlined` and `Icons.close`; side actions use icon glyphs, not text labels.
  - `_QuestionTypeLabel` lines around 2886-2892: canonical Chinese labels include `根据英文例句选择中文释义`, `根据含义填写词根/词缀`, `根据词根/词缀填写含义`.
  - `_RootAffixRelatedWords` lines around 2744+ exists; root/affix mode is a first-class study mode.
  - `_choiceState` and `_isCorrectChoice` lines around 2485-2542: feedback marks correct choice and user wrong choice simultaneously.

- `apps/flutter_mobile/lib/features/report_screen.dart` or equivalent report widgets:
  - The chart plot guide, line segment, touch dot, and selected dot must share the same x/y coordinate system. Mini-program must not keep hard-coded CSS `top/left/width` values that disagree with `buildReportChartPoints`.

### Mini-Program Current Fault Anchors

- `apps/wechat_miniprogram/src/pages/study/index.tsx`
  - `questionTypeLabels` currently contains mojibake.
  - `applySubmitResponse` updates `session.currentQuestion` immediately to `answer.currentQuestion`, while `buildStudyFeedItems` appends answered questions then pushes current unanswered. Because `visiblePageIndex` is always moved to `feedItems.length - 1`, the UI jumps to the next unanswered question and hides the feedback card.
  - `StudyIcon` returns an empty `Text`, while `index.scss` uses `content: "home"` etc.; WeChat renders literal icon words.
  - JSX text in completion/result blocks contains mojibake and malformed fragments.

- `apps/wechat_miniprogram/src/pages/study/index.scss`
  - `.study-icon--home::before { content: "home"; }`, `.study-icon--close::before { content: "close"; }`, and side-action pseudo CSS leak text or malformed shapes.
  - `.choice__marker` is text-sized and not styled as Flutter-like red/green feedback.

- `apps/wechat_miniprogram/src/components/Screen.tsx` and `Screen.scss`
  - `AppIcon` still renders the icon name as text.
  - Bottom nav icons rely on literal names (`today`, `tune`, `menu_book`, `query_stats`), causing text labels in the tab bar.

- `apps/wechat_miniprogram/src/pages/today/index.tsx`
  - `taskRows` omits `rootAffix`.
  - `completed` is hard-coded to `0`, so mid-session/resume progress cannot appear.
  - No refresh/restart affordance is exposed for recovering from stale state.

- `apps/wechat_miniprogram/src/sdk/client.ts`
  - `submitAnswer` only mutates Today on completion through `applyCompletedSessionToToday`; it does not update `today.resumeHint` after partial progress.
  - `applyCompletedSessionToToday` uses `summary.totalQuestions / summary.totalQuestions` instead of a literal increment, which is brittle.
  - `getResumeSessionHint` reads `today.resumeHint`, so partial-session sync should write there.

- `apps/wechat_miniprogram/src/pages/reports/index.tsx` and `index.scss`
  - `modeNames` and page title contain mojibake/broken JSX.
  - CSS chart guides use fixed `top: 96px`, `height: 84px`, `width: 266px`, while `buildReportChartPoints` uses `REPORT_CHART_HEIGHT=140`, `REPORT_CHART_TOP_GUTTER=12`, dynamic `plotHeight`, dynamic `plotWidth`.

```ts
useEffect(() => {
```

with logic:

```ts
useEffect(() => {
  if (!feedItems.length) return;
  const feedbackQuestionId = pendingFeedbackQuestionIdRef.current;
  if (feedbackQuestionId) {
    const feedbackIndex = feedItems.findIndex(
      (item) => item.kind === 'answered' && item.question.questionId === feedbackQuestionId,

      setVisiblePageIndex(feedbackIndex);
      pendingFeedbackQuestionIdRef.current = undefined;
      return;
    }
  }
  if (completion) {
    setVisiblePageIndex(feedItems.length - 1);
  }
}, [completion, feedItems]);
```
