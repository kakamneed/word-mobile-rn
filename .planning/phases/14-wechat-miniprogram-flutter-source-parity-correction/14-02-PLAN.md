<task id="14-02-04">
<title>Wire side actions to Flutter-equivalent behavior</title>
<action>
Ensure the five right-side actions behave like Flutter:
- hint opens current hint if `question.hasHint`, otherwise disabled or toast without submitting.
- comments opens the word comments path or a clearly disabled state if backend path is unavailable.

- dispute only works on an answered current/last submitted item; otherwise disabled or toast.

Do not make any of these buttons plain text labels.
</action>
