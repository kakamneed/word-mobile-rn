《respiratory-origin-2023》医学词根词缀整理

说明：
1. 医学英语常见构词方式：前缀 + 词根 + 后缀。
2. 前缀常表示“位置、程度、方向、否定”；词根决定核心含义；后缀常提示“炎症、疾病、检查、术式、状态”。
3. 下面优先整理源文件中反复出现、或对呼吸医学阅读最有帮助的词根词缀。

一、常见前缀

a- / an-    无；缺乏
  例：apnea（呼吸暂停）

anti-       抗；对抗
  例：antitrypsin（抗胰蛋白酶）

dys-        异常；困难；不良
  例：dyspnea（呼吸困难），dysfunction（功能障碍）

hyper-      高；过多；过强
  例：hypertension（高压/高血压），hypercapnia（高碳酸血症）

hypo-       低；不足；减少
  例：hypoxia（缺氧），hypoxemia（低氧血症）

inter-      在……之间
  例：interstitial（间质的）

intra-      在内；内部
  例：intracellular（细胞内的）

para-       旁；邻近；异常
  例：paracicatricial（瘢痕旁的）

non-        非；无
  例：noninvasive（无创的）

sub-        下；次级；低于
  例：submassive（次大面积的）

endo-       内；向内
  例：endotracheal（气管内的）

extra-      外；在……之外
  例：extrapulmonary（肺外的）

trans-      穿过；经由
  例：transbronchial（经支气管的）

三、常见后缀

-itis       炎症
  例：bronchitis（支气管炎），rhinitis（鼻炎）

-osis       病态；异常状态；病症
  例：fibrosis（纤维化），acidosis（酸中毒），alkalosis（碱中毒）

-oma        瘤；肿瘤
  例：carcinoma（癌），lymphoma（淋巴瘤）

-emia       血症；血液状态
  例：hypoxemia（低氧血症）

-pnea       呼吸
  例：apnea（呼吸暂停），dyspnea（呼吸困难），tachypnea（呼吸过速）

-oxia       氧状态
  例：hypoxia（缺氧），anoxia（无氧）

-scopy      镜检查
  例：bronchoscopy（支气管镜检查）

-metry      测量；测定法
  例：spirometry（肺通气功能测定）

-gram / -graphy   图；记录；描记；造影
  例：angiography（血管造影）

-ectomy     切除术
  例：lobectomy（肺叶切除术）

-plasty     成形术；修补术
  例：tracheoplasty（气管成形术）

-stomy      造口术
  例：tracheostomy（气管造口术）

-centesis   穿刺术
  例：thoracentesis（胸腔穿刺术）

-lysis      分解；溶解；松解
  例：fibrinolysis（纤维蛋白溶解）

-genic / -genous   由……引起；来源于
  例：enterogenic（肠源性的），enterogenous（肠源性的）

-al / -ary / -ory / -ic / -ous / -ive   形容词后缀，表示“……的”
  例：pulmonary（肺的），respiratory（呼吸的），bronchial（支气管的），invasive（有创的）

-tion / -sion   过程；行为；状态
  例：ventilation（通气），diffusion（弥散），perfusion（灌注），aspiration（误吸/抽吸）

四、拆词示例

hypoxemia = hypo- + ox + -emia
含义：血氧低于正常，即“低氧血症”。

bronchoscopy = bronch/o + -scopy
含义：用镜检查支气管，即“支气管镜检查”。

bronchitis = bronch- + -itis
含义：支气管的炎症，即“支气管炎”。

pneumothorax = pneum/o + thorax
含义：空气进入胸腔形成“气胸”。

endotracheal = endo- + trache- + -al
含义：位于气管内的，即“气管内的”。

carcinoma = carcin/o + -oma
含义：癌性肿瘤，临床常简译为“癌”。

tuberculous = tubercul- + -ous
含义：与结核相关的，即“结核性的”。

ventilatory = ventil- + -ory
含义：与通气有关的，即“通气的”。
